## 2026-10-29

### 지구본 표면 표시 수정

- 3D 지구본의 삼각형 감기 순서가 좌표계 수정 뒤 반대로 되어 앞면이 잘리던 문제를 고쳤습니다. 이 때문에 지구본이 반투명하거나 속이 빈 것처럼 보였습니다.
- 대기광을 지구 가장자리에만 보이게 바꾸고, 카메라를 따라오는 햇빛을 더해 어느 각도에서 돌려도 대륙과 해양 표면이 보이도록 조정했습니다.
- 지형의 해양·대륙 색 대비와 조명을 조정해 표면이 더 또렷하게 보이도록 했습니다.
- 아메리카, 태평양, 대서양, 남반구 방향으로 직접 돌려 표면 표시를 확인했습니다.
- Vitest 단위 테스트 49개, Playwright 브라우저 테스트 13개를 다시 통과했습니다.

### 판 위치·이름·단면도 방향 점검

- 판 경계 카드와 개념 단면도의 좌우 순서를 실제 지리적 위치(서→동, 경계가 동서 방향이면 남→북)에 맞추었습니다.
  - 태평양판–북아메리카판 경계는 이제 태평양판이 왼쪽(서쪽), 북아메리카판이 오른쪽(동쪽)에 표시됩니다.
  - 안데스 경계는 나스카판이 왼쪽, 남아메리카판이 오른쪽에 표시됩니다.
- 단면도에서 섭입하는 해양판이 상대 판 아래로 내려가도록 단면 방향을 고쳤습니다.
- 대륙-대륙 충돌 단면도는 인도-오스트레일리아판(남쪽)에서 유라시아판(북쪽) 순서로 표시합니다.
- 판 이름을 점검해 `필리핀해판`, `아프리카판(누비아)`, `아프리카판(소말리아)`로 더 분명하게 표시했습니다.
- 판 모자이크를 지도로 다시 확인해 태평양판이 북아메리카판의 서쪽에 있고, 나스카판이 남아메리카판의 서쪽에 있는 것을 확인했습니다.
- 3D 지구본의 위경도→3D 좌표 변환을 표준 지도 방향(북쪽 위, 동쪽 오른쪽)에 맞추어, 태평양을 중심으로 볼 때 아시아·호주가 왼쪽, 아메리카가 오른쪽에 오도록 했습니다.
- 단위 테스트 49개, 브라우저 테스트 13개로 방향과 이름을 검증합니다.

### TerraShift MVP 구현

- Vite + TypeScript + Three.js 기반의 정적 지구과학 수업 앱을 새로 만들었습니다.
- 수업용 12개 판 모자이크(태평양, 북아메리카, 남아메리카, 누비아, 소말리아, 유라시아, 인도-오스트레일리아, 남극, 나스카, 코코스, 필리핀, 카리브)를 넣었습니다.
  - 동아프리카 열곡 수업을 위해 아프리카판을 누비아판과 소말리아판으로 나누었습니다.
  - 실제 측지 자료가 아닌 단순화한 수업용 모자이크입니다.
- 위도·경도 격자에서 판 경계를 추출하고, 상대 속도의 수렴·발산·미끄러짐 성분으로 발산·수렴·변환 경계와 세 가지 수렴 하위 유형을 분류합니다.
- 96×192 지형 격자와 5 Myr 간격 키프레임을 만들고, 0–200 Myr 시간 이동에 따라 해령 융기, 대륙 열곡, 해구, 산맥, 화산호, 고원, 변환 단층 지형이 변하도록 했습니다.
- 해양 지각 나이 색상 층과 판 색 층을 넣었습니다.
- 결정론적 지진·화산 카탈로그를 만들었습니다. 지진은 깊이별 색과 규모별 크기로, 화산은 분출 펄스가 있는 원뿔로 표시합니다. 변환 경계에는 화산을 배치하지 않습니다.
- 선택한 경계에 따라 해구·산맥·화산호·열곡·단층을 그리는 개념 단면도를 넣었습니다. 단면도는 실제 지질 단면이 아닌 개념 그림임을 표시합니다.
- 여섯 미션(경계 읽기, 대륙 충돌, 해양-대륙 수렴, 변환 단층, 대륙 열곡, 불의 고리)을 예측·설명 두 단계로 구현했습니다. 진행 상황과 점수는 브라우저에 저장됩니다.
- 교사 모드에 정답·해설 표, 수업 장면 바로 열기, 진행 초기화, 활동지 인쇄를 넣었습니다.
- 활동지는 빈 세계 지도, 경계 유형별 지진 수 표, 여섯 미션 질문으로 구성했습니다.
- 데스크톱·태블릿·휴대폰 레이아웃을 만들었습니다. 태블릿에서는 패널 서랍, 휴대폰에서는 시간·층·선택/미션 탭을 사용합니다.
- 키보드 조작(Space, 방향키, [ ], L, 1/2), 화면 읽기 요약, 동작 줄이기, 색 외에 선 모양과 이름표로 경계 유형을 구분하는 장치를 넣었습니다.
- PWA 매니페스트, 앱 아이콘, 서비스 워커를 넣어 첫 로드 뒤 오프라인에서도 실행되도록 했습니다.
- 개념 모델·실제 예보 아님 배지, 고도 40× 과장 배지를 넣었습니다.

### 검증

- Vitest 단위 테스트 49개 통과: 구면 기하, 판 격자, 경계 분류, 지형 부호, 결정론, 지진·화산 분포, 미션 경계, 저장, 시간 보간, 단면도.
- Playwright 브라우저 테스트 13개 통과: 지구본 로드, 시간 스크럽, 키보드 경계 선택·단면도, 여섯 미션 완료, 진행 저장·초기화, 휴대폰 패널, 인쇄 화면, 동작 줄이기, 외부 API 호출 없음, axe 접근성 검사.
- 프로덕션 빌드와 PWA 프리캐시를 확인했고, 오프라인 새로고침에서도 화면이 열리는 것을 확인했습니다.
- 1440×900, 1024×768, 390×844 화면을 확인했습니다.

### 실행

```bash
npm install
npm run dev
```

빌드와 테스트는 다음 명령으로 실행합니다.

```bash
npm run build
npm test
npm run test:e2e
```

### 참고

- 이 앱은 수업용 개념 모델입니다. 실제 지진·화산을 예측하지 않으며, 실제 지질도나 측지 자료로 사용하면 안 됩니다.
- 지형 고도는 40배 과장되어 있고, 판의 모양과 운동은 수업을 위해 단순화했습니다.
